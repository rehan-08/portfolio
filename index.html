02 / Selected work

Ideas, made tangible.

A selection of projects across intelligent systems, geospatial analysis, embedded technology, and software development.

PROJECT / 01 · ENVIRONMENT⌁

Samudra — Mahim Bay

An IoT water-quality monitoring prototype designed for Mahim Bay. An ESP32-based floating buoy collects readings from pH, turbidity, TDS, and temperature sensors, with LoRa communication carrying field data toward a remote monitoring dashboard. The project focuses on practical environmental monitoring, low-power deployment, and marine-ready hardware.

ESP32IoTLoRapH / TDSTurbidity
PROJECT / 02 · INTELLIGENCE◎

GeoMonitor

An India-centric geopolitical intelligence dashboard for following global developments through geographic context. The project brings together event monitoring, map-based visualization, and AI-assisted analysis to help users understand where developments are unfolding and why they matter.

GeospatialData VisualizationAI-assisted AnalysisIntelligence
PROJECT / 03 · DATA & RESEARCH⌖

Commodity Trade Disruption Tracker

A self-initiated Python tool that pulls commodity-trade updates from public Telegram channels to monitor import activity. It flags commodities potentially affected by wars or disasters, surfaces price and supply disruption alerts in a dashboard, and generates contingency recommendations to help sustain trade flow. The project is particularly relevant to strategic maritime chokepoints such as the Strait of Hormuz, where conflict or disruption can affect commodity flows.

PythonTelegram APIData MonitoringDashboard
PROJECT / 04 · ACCESSIBILITY⌁

NeuroSynapse — Sign-to-Speech Glove

A team-developed wearable assistive glove using flex sensors and an ESP32 microcontroller to capture hand-gesture data for sign-language recognition. A neural-network classifier maps gestures to outputs, with Google API integration producing audible English, Hindi, and Marathi. A companion app uses cloud storage to log and sync gesture and conversion data.

ESP32Flex SensorsNeural NetworkGoogle APICloud Storage
PROJECT / 05 · LEARNING TOOLS▥

DSA Visualizer

A web-based algorithm animation platform built with React.js and Tailwind CSS. It visualizes data-structure and algorithm concepts step by step, with an interactive responsive interface designed to make learning clearer for beginners. The project emphasizes reusable components and maintainable UI structure.

React.jsTailwind CSSAlgorithmsResponsive UI
PROJECT / 06 · GEOSPATIAL⌘

SafeCity

A geospatial analytics concept exploring how location-aware data and machine-learning-assisted insights could support urban safety monitoring. The proposed direction includes spatial data handling, mapping, and an interactive dashboard. This is presented as a concept rather than a claim of a completed production system.
